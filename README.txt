PORTOFOLIO HIJAU - MUHAMAD PURNAMA SALURA

Cara menjalankan:
1. Extract file ZIP.
2. Buka folder portfolio-hijau.
3. Klik dua kali index.html atau buka menggunakan Live Server di VS Code.
4. Pada bagian Proyek, klik tombol "Lihat Project" di Website Kasir untuk mencoba demonya.
5. Klik "Lihat Prototype" pada proyek Mockup & Prototype untuk membuka desain Figma.
6. Klik "Lihat Studi Kasus" pada Website Usability Testing untuk membaca temuan dan rekomendasi.

Website Kasir adalah demo frontend tanpa backend. Transaksi hanya simulasi dan
tidak memproses pembayaran sungguhan.

Folder assets berisi:
- Foto profil
- Gambar proyek aplikasi kasir
- Gambar proyek UI/UX Instagram
- Gambar proyek website sekolah
- Gambar proyek website portofolio
