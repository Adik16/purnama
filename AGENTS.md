# Project Instructions

## Project Overview
- This is a static, Indonesian-language personal portfolio for Muhamad Purnama Salura.
- The site is implemented in `index.html`; its CSS and small navigation script are inline.
- There is no package manager, build step, or automated test suite configured.
- `README.txt` describes opening `index.html` directly or using VS Code Live Server.

## Project Structure
- Keep the site lightweight and dependency-free unless a task clearly requires otherwise.
- Place reusable image assets in `assets/`. Check existing files before adding or renaming assets.
- Preserve the current language, personal details, and visual direction unless asked to change them.
- Keep image references consistent with actual file locations when editing portfolio content.

## Changes and Validation
- Prefer focused edits that follow the existing HTML, CSS, and JavaScript conventions.
- For content or style changes, open `index.html` in a browser and check desktop and narrow/mobile layouts.
- For script changes, verify the affected interaction in a browser, including the responsive navigation when relevant.
- Do not add a build or test workflow unless the project setup is intentionally changed.
